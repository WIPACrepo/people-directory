# PLAN: Modernize `people-directory` to `pyproject.toml`, Updated Deps, and New WIPAC CI/CD

**Goal:** Migrate this Python package from `setup.py`/`setup.cfg` to PEP 621 `pyproject.toml`,
refresh dependencies, and update GitHub Actions to match the current WIPACrepo pattern
(reference: https://github.com/WIPACrepo/iceprod).

**Decisions (confirmed by owner):**
| # | Question | Decision |
|---|---|---|
| 1 | Python range | **Update to `>=3.12, <3.15`** (like iceprod; 3.10 is EOL Oct 2026) |
| 2 | PyPI publishing | **Keep unpublished** → `mode: PACKAGING`, `publish-to-pypi: false`, no `PYPI_TOKEN` |
| 3 | `motor` dep | **Keep** (declared dependency, even if not currently imported) |
| 4 | Tests | **(a) Smoke/import check only** — no pytest (no tests exist), no coverage gating |
| 5 | Docker | **`BUILD` only** — no CVMFS, no cvmfs secrets |
| 6 | Filename | **Rename** to `wipac-cicd.yml` (iceprod style); delete `docker.yaml` |
| 7 | `setup.py` | **Delete** |
| 8 | ruff rules | **Defaults** (`ruff-modernize-rules: I,FA`; max-complexity 15, max-statements 50) |

## 1. Phase 1 — `pyproject.toml` (PEP 621 migration)

Create `pyproject.toml` by migrating `setup.cfg` sections. Fields the CI action regenerates are marked
`# do not edit — autogenerated by wipac-dev-py-setup-action` and must be kept consistent with the
`py-setup` workflow inputs (§3).

- `[build-system]`
  - `requires = ["setuptools>=78.1", "setuptools-scm"]`
  - `build-backend = "setuptools.build_meta"`
- `[project]`
  - `name = "people-directory"`
  - `description = "Populate a basic web directory with users from Keycloak"` (from README)
  - `readme = "README.md"`
  - `license = "MIT"`, `license-files = ["LICENSE"]`
  - `keywords = ["WIPAC"]` (optional; not required since unpublished)
  - `classifiers` for 3.12, 3.13, 3.14
  - `requires-python = ">=3.12, <3.15"`
  - `dynamic = ["version"]` + `[tool.setuptools_scm]` (`fallback_version = "CANNOT_BUILD_WITHOUT_GIT_DIR"`)
  - `dependencies = [ 'motor', 'tornado', 'wipac-dev-tools', 'wipac-keycloak-rest-services', 'wipac-rest-tools' ]`
    - ✅ keep `motor` (decision #3)
    - ➕ add `tornado` (direct import in `server.py`; currently transitive)
  - `[project.optional-dependencies]`
    - `tests = [ 'coverage', 'pytest', 'pytest-asyncio', 'pytest-cov', 'pytest-mock', 'ruff' ]`
      (flake8 removed — ruff replaces it; kept for future testing despite smoke-only CI)
    - `mypy` — generated by `auto_mypy_option: True` (kept for parity; ty runs in lint)
  - `[[project.authors]]` name = `WIPAC Developers`, email = `developers@icecube.wisc.edu`
  - `[project.urls]` — **no PyPI page** (unpublished): `Homepage = "https://github.com/WIPACrepo/people-directory"`,
    `Tracker = ".../issues"`, `Source = "https://github.com/WIPACrepo/people-directory"`
- `[tool.setuptools]`
  - `packages = ['people_directory']` (single package; from `package_dirs = people_directory`)
  - `[tool.setuptools.package-data]` `"*" = ["py.typed", "static/*"]` — **must include `people_directory/static/`**
    (HTML/CSS/JS/icons are served at runtime; without this the wheel is broken)
- Lint/test config migrations (from `setup.cfg`):
  - `[flake8]` → `[tool.ruff]` + `[tool.ruff.lint]`: `ignore = ["E203","E226","E228","E231","E501","W503","W504"]`, `exclude = ["env","tests"]`
  - `[tool:pytest]` → `[tool.pytest.ini_options]`: `markers = ["role"]`
  - `[coverage:run]` / `[coverage:report]` / `[coverage:html]` → `[tool.coverage.run]` (`branch = True`, `source = ["people_directory"]`),
    `[tool.coverage.report]` (`exclude_lines`, `ignore_errors`, `skip_empty`), `[tool.coverage.html]` (`directory = "htmlcov"`)
  - `[tool.mypy]` / `[tool.ty]` if auto-generated — exclude tests/docs if present
- **Delete `setup.cfg`** entirely (including `[wipac:cicd_setup_builder]` → workflow inputs, and `[semantic_release]` → replaced by next-version-action + tag-and-release).

## 2. Phase 2 — Version handling (setuptools-scm)

- Remove `__version__` and `version_info` from `people_directory/__init__.py`.
  - setuptools-scm owns the version; `tag-and-release.yml` **fails** if `[project] version` is static or
    `[tool.setuptools_scm]` is missing.
- Grep repo-wide for `__version__` / `version_info` usage before deleting (old semantic-release was the only
  consumer; `CHANGELOG.md` references are historical only).
- Pipeline: `wipac-dev-next-version-action@v1.8` (`force-patch-if-no-commit-token: true`, `ignore-paths` incl.
  `.github/**`, `**/README.md`, `.gitignore`) → `tag-and-release.yml@v1.33` tags `vX.Y.Z`, builds `dist/` via
  `python -m build` (setuptools-scm reads git tags).
- `CHANGELOG.md` `<!--next-version-placeholder-->` is a python-semantic-release artifact → remove marker line
  (keep changelog history).

## 3. Phase 3 — GitHub Actions rewrite (match iceprod)

### New `.github/workflows/wipac-cicd.yml` (replaces `wipac_cicd.yaml`; delete `docker.yaml`)

`on: push: branches: ['**'], tags-ignore: ['**']` (same trigger as iceprod).

1. **`py-versions`**
   - `actions/checkout@v7` with `ref: ${{ github.sha }}` (lock to triggered commit)
   - `WIPACrepo/wipac-dev-py-versions-action@v2.8` → `outputs.matrix` (parses `requires-python` → 3.12, 3.13, 3.14)

2. **`lint-python`** (`needs: [py-versions]`)
   - Reusable: `WIPACrepo/wipac-dev-workflows/.github/workflows/lint-python.yml@v1.33`
   - `with: py-matrix-json: ${{ needs.py-versions.outputs.matrix }}`
   - `max-complexity: 15`, `max-statements: 50` (defaults)
   - `ruff-modernize-rules: I,FA` (default — decision #8)
   - Runs `ruff`, `ty`, `ruff-modernize` (branch-touched lines). Removes old `wipac-dev-flake8-action` + hardcoded `py_version: '3.10'`.

3. **`py-setup`**
   - `if: ${{ github.actor != 'dependabot[bot]' }}`
   - `actions/checkout@v7` with `token: ${{ secrets.PERSONAL_ACCESS_TOKEN }}`, `ref: ${{ github.ref }}` (action pushes)
   - `WIPACrepo/wipac-dev-py-setup-action@v5.12`:
     - `mode: PACKAGING` (unpublished — no `pypi_name`, no author/keywords required, Homepage=GitHub)
     - `python_min: "3.12"`, `python_max: "3.14"`
     - `package_dirs: people_directory`
     - `auto_mypy_option: True`
   - Regenerates `pyproject.toml` metadata, `README.md` badges (GitHub-only badges, no PyPI), and mypy extra.

4. **`py-dependencies`**
   - `actions/checkout@v7` with `fetch-depth: 0`, `ref: ${{ github.sha }}`
   - `WIPACrepo/wipac-dev-py-dependencies-action@v3.4` → uploads `py-dependencies-logs` artifact
     (consumed by tag-and-release as `release-artifacts`)

5. **`tests`** (`needs: [py-versions]`) — **smoke-only (decision #4)**
   - `strategy: matrix: py3: ${{ fromJSON(needs.py-versions.outputs.matrix) }}`, `fail-fast: false`
   - `actions/checkout@v7` (`fetch-depth: 0`), `actions/setup-python@v7` (`python-version: ${{ matrix.py3 }}`)
   - `pip install --upgrade pip wheel setuptools && pip install .[tests]`
   - Smoke check (no pytest — no test files):
     `python -m compileall people_directory`
     `python -c "import people_directory, people_directory.server, people_directory.people"` (imports `krs`, `rest_tools`, `wipac_dev_tools`, `tornado` — verifies deps resolve)
   - **Do not** import `people_directory.__main__` (it starts the server).

6. **`docker-build`** (`needs: [py-versions]`? — in iceprod it's independent; keep after tests)
   - `if: ${{ github.ref != 'refs/heads/master' && github.ref != 'refs/heads/main' }}` (validate, don't publish on PR/branch)
   - `actions/checkout@v7` (`fetch-depth: 0`), `docker/setup-buildx-action@v4`, `docker/build-push-action@v7` with `push: false`

7. **`release-version`**
   - `if: format('refs/heads/{0}', github.event.repository.default_branch) == github.ref`
   - `needs: [py-versions, lint-python, py-setup, py-dependencies, tests]`
   - `actions/checkout@v7` (`fetch-depth: 0`, `ref: ${{ github.sha }}`)
   - `WIPACrepo/wipac-dev-next-version-action@v1.8` with `force-patch-if-no-commit-token: true` and `ignore-paths`:
     `**/README.md`, `.github/**`, `.gitignore`

8. **`tag-and-release`** (reusable)
   - `if: default-branch && needs.release-version.outputs.next-version != ''`
   - `uses: WIPACrepo/wipac-dev-workflows/.github/workflows/tag-and-release.yml@v1.33`
   - `permissions: contents: write`
   - `with: project-type: python, python-version: "${{ fromJSON(needs.py-versions.outputs.matrix)[0] }}",
     release-artifacts: py-dependencies-logs, publish-to-pypi: false`
   - **No `secrets.PYPI_TOKEN`** (unpublished — decision #2). `TOKEN` optional (not needed).

9. **`image-publish`** (reusable)
   - `if: default-branch && next-version != ''`, `needs: [tag-and-release, release-version]`
   - `uses: .../image-publish.yml@v1.33`, `permissions: packages: write`
   - `with: image_namespace: wipacrepo, image_name: people-directory, mode: BUILD` (decision #5 — **no CVMFS**),
     `build_args: VERSION=${{ needs.release-version.outputs.next-version }}`,
     `extra_build_tag: ${{ needs.release-version.outputs.next-version }}`
   - No `cvmfs_github_token` secret. ghcr auth via `GITHUB_TOKEN` (automatic).
   - Builds amd64+arm64 by default; tags via metadata action (branch, semver, extra tag).

- **`wipac_cicd.yaml`** → renamed content into `wipac-cicd.yml`.

### Secrets required (no new ones beyond existing)

- `GITHUB_TOKEN` — implicit

## 4. Phase 4 — Dockerfile update (match iceprod, BUILD-compatible)

- `FROM python:3.14` (or `3.12` — use `python_max` base; iceprod uses `python:3.14`)
- `RUN groupadd -g 1000 app && useradd -m -g 1000 -u 1000 app`
- `RUN mkdir /app`; `WORKDIR /app`
- Copy only needed inputs: `pyproject.toml`, `README.md`, `LICENSE`, `people_directory/`
  (replaces `COPY . .`; keeps layer cache healthy)
- `RUN git config --global --add safe.directory /app`
- `ENV VIRTUAL_ENV=/app/venv`; `RUN python3 -m venv $VIRTUAL_ENV`; `ENV PATH="$VIRTUAL_ENV/bin:$PATH"`
- `ARG VERSION`; `ENV SETUPTOOLS_SCM_PRETEND_VERSION_FOR_PEOPLE_DIRECTORY=$VERSION`
- `RUN --mount=type=bind,source=.git,target=.git,ro pip install --no-cache -e .`
  (setuptools-scm needs git metadata; version injected via `build_args: VERSION=...` from workflow)
- Drop `COPY . .` / `ENV PYTHONPATH=/home/app` / double `USER` churn
- Keep `CMD ["python", "-m", "people_directory"]`
- ⚠️ Dockerfile must be buildable *without* git (e.g. `container.yml` manual run on a tag-less checkout):
  bypass via `SETUPTOOLS_SCM_PRETEND_VERSION_FOR_*` (set in ARG) — the bind-mount of `.git` is read-only
  and the action checks out with `fetch-depth: 0`; safe.

## 6. Phase 6 — Validation checklist (when implementation begins)

1. Clean venv: `pip install -e .[tests]` — resolves all deps under Python 3.12–3.14.
2. `python -m build` in a git-tagged clone → verifies setuptools-scm versioning (and that static/ is packaged:
   `unzip -l dist/*.whl | grep static`).
3. `ruff check .` + `ty check` (new configs) — expect only pre-existing issues; fix or ignore list.
4. Push branch → run `wipac-cicd.yml`: py-versions, lint-python, py-setup (writes pyproject), py-dependencies, tests (smoke), docker-build all green.
5. Merge to default → release-version → tag-and-release (tag `vX.Y.Z`, GH release w/ `dist/*` + `py-dependencies-logs`) → image-publish (`wipacrepo/people-directory` on ghcr.io, multi-arch).
6. Deploy smoke: run container locally with `VERSION` build-arg; hit `/healthz` and `/` (static assets present).

## 7. Risks / Notes

- **`py-setup` action rewrites `pyproject.toml`** — keep "do not edit" fields consistent with workflow inputs to avoid diff churn on every push.
- **setuptools-scm needs git history** — every git-dependent checkout must use `fetch-depth: 0`; shallow checkouts break version detection (reusable workflows handle this; our local `docker-build` should too).
- **Old tags are `1.0.13` (no `v`)** — new pipeline tags `v1.0.14`+; the first release computes the next version from the existing `1.0.13` tag. Verify setuptools-scm finds the `1.0.13` tag for version math (it matches bare semver; if not, first version may compute oddly — confirm on first run and, if needed, tag `v1.0.14` manually once).
- **`people_directory/static/`** must be in package-data or the deployed image 404s on assets — verified in Phase 6 step 2.
- **Removing `__version__`** may break external importers (rare) — grep first.
- **Smoke-only CI** (no tests) means no coverage gate; if tests are added later, add `coverage run --fail-under` back and adjust `tests` job.
- **Python 3.12 minimum** — code uses deprecated `asyncio.get_event_loop()` (warning only, still works in 3.12/3.13); optional follow-up refactor, not blocking.
