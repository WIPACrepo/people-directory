# PLAN: Modernize `people-directory` to `pyproject.toml`, Updated Deps, and New WIPAC CI/CD

**Goal:** Migrate this Python package from `setup.py`/`setup.cfg` to PEP 621 `pyproject.toml`,
refresh dependencies, and update GitHub Actions to match the current WIPACrepo pattern
(reference: https://github.com/WIPACrepo/iceprod — see my analysis below).

## 8. Risks / Notes

- **`py-setup` action rewrites `pyproject.toml`** — keep all "do not edit" fields consistent or the action may churn diffs every push; treat generated metadata as CI-owned.
- **setuptools-scm requires git history** — all `git`-dependent checkout steps must use `fetch-depth: 0`; shallow checkouts break version detection (the released workflows handle this).
- **Version format:** old tags are `1.0.13` (no `v`). `wipac-dev-next-version-action`/`tag-and-release` create `v`-prefixed tags (`v1.0.14`). Decide whether to keep `v` prefix (recommended; iceprod uses it) — previous tags without `v` may not be found by setuptools-scm for version calc on the first release (verify on first run).
- **`people_directory/static/`** must be included in the wheel (package-data) or the deployed image will 404 on assets — verify after `pip install`/wheel build.
- **Removing `__version__`** may break external importers (rare) — grep repo-wide first.
- **No tests** means `pytest`/coverage jobs need an explicit smoke step or they fail with "no tests collected".
